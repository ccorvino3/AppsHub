## 🚀 Le Mie Applicazioni

### 🎬 TRACE (Watched Tracker)
> *Traccia film, serie TV, anime, manga, libri e videogiochi con statistiche avanzate, assistente vocale AI e supporto offline.*

| Dettaglio | Informazione |
| :--- | :--- |
| **Versione attuale** | `v0.1.41` |
| **Requisiti minimi** | Android 8.0 (API 26+) |
| **Tecnologie** | Kotlin, Jetpack Compose, Room, Hilt, Material You, Gemini AI |
| **Download APK** | [⬇️ Scarica Ultima Release](https://github.com/ccorvino3/WatchedTracker/releases/latest) |
| **Codice sorgente** | [Watched-Tracker](https://github.com/ccorvino3/WatchedTracker) |

#### Funzionalità principali:
- 📊 **Statistiche e Wrapped**: grafici dettagliati, riepiloghi mensili/annuali condivisibili e sfide personalizzate.
- 🎙️ **Assistente Vocale AI**: gestione completa della libreria tramite comandi in linguaggio naturale.
- 🗂️ **Organizzazione flessibile**: cartelle nidificate, tag, citazioni, stagioni a lunghezza variabile e rewatch.
- 📱 **Widget Home**: aggiornamento rapido dei progressi dalla schermata iniziale.
- 🔒 **Privacy totale**: database 100% offline e cartelle protette da password.

## 📥 Come Installare gli APK su Android

1. Scarica il file `.apk` dalla tabella qui sopra o dalla sezione [Releases](../../releases).
2. Apri il file scaricato tramite le notifiche o il gestore file del telefono.
3. Se richiesto da Android, consenti l'installazione da *"Origini sconosciute"* per il browser o gestore file utilizzato.
4. Premi **Installa** e avvia l'applicazione.
