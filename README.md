## 📥 Come Installare gli APK su Android

1. Scarica il file `.apk` dalla tabella qui sopra o dalla sezione [Releases](../../releases).
2. Apri il file scaricato tramite le notifiche o il gestore file del telefono.
3. Se richiesto da Android, consenti l'installazione da *"Origini sconosciute"* per il browser o gestore file utilizzato.
4. Premi **Installa** e avvia l'applicazione.
